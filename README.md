# GDG on Campus – RIT Hassan | Club Website

A responsive, single-page website for **GDG on Campus – Rajeev Institute of Technology, Hassan, Karnataka**. It introduces the club, showcases events (including **CodeStorm 2026**), lists the Google technologies the club covers, and gives students easy ways to join the community.

Built with plain **HTML, CSS and JavaScript**. No frameworks and no build step.

## Live Demo
https://gdg-club-website.vercel.app/


`https://pavip6497-source.github.io/GDG-Club-Website/`

## Features

- Sticky navbar with active-section highlighting and a mobile hamburger menu
- Animated hero section with floating shapes and counting stats
- Scroll-reveal animations and smooth scrolling
- Glassmorphism cards with a mouse-glow hover effect
- Featured event section for **CodeStorm 2026** with registration and WhatsApp links
- Programs section: Web, Cloud, AI and Android
- Community links: WhatsApp, Instagram, GitHub
- Team section and contact section
- Back-to-top button and button ripple effects
- Fully responsive (desktop, tablet, mobile)

## Getting Started

### Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/pavip6497-source/GDG-Club-Website.git
   cd GDG-Club-Website
   ```
2. Open `index.html` in your browser (just double-click it).

Or use a local server, for example with VS Code's **Live Server** extension.

> An internet connection is needed to load Google Fonts and Font Awesome icons from their CDNs.

## Deployment

The easiest free option is **GitHub Pages**:

1. Push the project to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Click **Save**. Your site will be live in a minute or two.

## Customization

- **Content and links:** edit `index.html` (event details, team members, WhatsApp, Instagram and form links).
- **Colors, fonts, layout:** edit `style.css`.
- **Animations and behavior:** edit `script.js`.
- **Images:** replace files in `assets/`, keeping the same file names, or update the paths in `index.html`.
